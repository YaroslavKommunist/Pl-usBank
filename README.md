# Pl'usBank

Мобильное банковское приложение для управления личными финансами

О приложении

Pl'usBank - это полнофункциональное PWA-приложение для управления личными финансами. Оно позволяет отслеживать доходы и расходы, управлять кредитами и вкладами, устанавливать финансовые цели и контролировать бюджет.

Основные возможности

Управление счетом
- Отображение текущего баланса
- Персонализированная банковская карта
- Статистика за день и неделю

Операции
- Добавление доходов с указанием источника
- Быстрые расходы по категориям
- Переводы между пользователями
- Регулярные платежи

Банковские продукты
- Оформление и управление кредитами
- Открытие и ведение вкладов
- Начисление процентов

Финансовый контроль
- Месячный бюджет
- Лимиты по категориям
- Цели накопления
- История операций

Дополнительные функции
- Сканер штрихкодов
- QR-синхронизация данных
- Темная/светлая тема
- Поддержка разных валют

Установка

Установка PWA

Android (Chrome):
1. Откройте приложение в Chrome
2. Нажмите на баннер "Установить Pl'usBank"
3. Подтвердите установку

iOS (Safari):
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться"
3. Выберите "На экран Домой"
4. Назовите приложение и нажмите "Добавить"

Desktop:
- Приложение работает в любом современном браузере
- Можно добавить в закладки для быстрого доступа

Быстрый старт

1. Настройка профиля
   - Нажмите на шестеренку в правом нижнем углу
   - Введите имя владельца карты
   - Выберите валюту и тему оформления

2. Добавление дохода
   - Перейдите на вкладку "Доходы"
   - Введите сумму и источник
   - Нажмите "Зачислить"

3. Добавление расхода
   - На вкладке "Главная" введите сумму
   - Выберите категорию
   - Нажмите "Списать"

4. Оформление кредита
   - Перейдите на вкладку "Кредиты"
   - Нажмите "+ Взять"
   - Заполните данные кредита

5. Открытие вклада
   - Перейдите на вкладку "Вклады"
   - Нажмите "+ Открыть"
   - Укажите сумму и ставку

Синхронизация данных

Для переноса данных между устройствами используйте QR-синхронизацию:

1. Экспорт (создание QR)
   - Откройте профиль
   - Нажмите "Создать QR"
   - Отсканируйте QR-код на другом устройстве

2. Импорт (сканирование QR)
   - Откройте профиль
   - Нажмите "Сканировать QR"
   - Наведите камеру на QR-код

Все данные хранятся локально в браузере и не передаются на внешние серверы

Темы оформления

- Светлая - для дневного использования
- Темная - для вечернего использования
- Как в системе - автоматическое переключение

Поддерживаются валюты: Рубль, Доллар, Евро, Тенге, Гривна, Фунт, Йена

Системные требования

- iOS: Safari 12+
- Android: Chrome 60+
- Desktop: любой современный браузер

Советы по использованию

1. Быстрые кнопки
   - Создавайте кнопки для частых трат
   - Настраивайте на вкладке "Регулярные"

2. Бюджетирование
   - Установите месячный бюджет
   - Настройте лимиты по категориям

3. Цели
   - Ставьте цели накопления
   - Отслеживайте прогресс

4. Регулярные платежи
   - Настройте автоматические платежи
   - Указывайте день списания

5. Резервное копирование
   - Регулярно создавайте QR-код для бэкапа
   - Храните резервные копии отдельно
